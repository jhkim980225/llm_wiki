## 요청 흐름

- **색인**: 개발 PC → NodePort `POST /documents/text` → 청킹(파드 내부, LLM 무관) → 개체·관계 추출(LUNA) → 임베딩(Ollama) → PVC 저장
- **질의(화면)**: 브라우저 → `/graphwiki/api/lightrag` → 앱 서버가 서비스 DNS로 `POST /query` → 키워드 추출(LUNA) → 그래프+벡터 검색(PVC) → 답변 생성(LUNA)
- **질의(직접)**: 개발 PC → NodePort `POST /query` (VPN 필요)
