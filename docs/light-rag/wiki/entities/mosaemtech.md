# 모샘테크

모샘테크((주)모샘테크)는 [[seongjin]]에 스킨케어 완제품 제조를 의뢰한 완제품 고객이다.
자체 브랜드 "모셀"로 광채 라인을 판매한다.

## 핵심 사실
- 대표: 민경준 (rhmin9981@hanmail.net)
- 브랜드명: 모셀
- 완제품: 광채크림(일반형/고급형), 광채마스크팩, 광채밤
- 2021년 9월부터 견적·전성분·문안 수정을 여러 차례 진행했다
