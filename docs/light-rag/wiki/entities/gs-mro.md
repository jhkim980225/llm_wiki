# 지에스

지에스(GS, gs.munguok.co.kr "문구몰")는 사무용품 인터넷쇼핑몰이자
[[seongjin]]의 거래를 대행하는 창구다. 원료 견적(MRO) 요청과
[[seoyeong-university]] 관련 견적서 전달 건으로 여러 차례 등장했다.

- 연락처: 062-527-2646, gs2646@naver.com
- 사이트: gs.munguok.co.kr ("문구몰")
