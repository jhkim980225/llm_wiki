# 강원대학교

강원대학교는 [[choi-damseon]]의 지인인 박철호 교수를 통해 연결된 교육기관이다. 2022년
4월 박철호 교수와 시제품 개발 협업 가능성을 논의했고, 이 과정에서 "세인트진"이라는
브랜드명을 제안받았다.

## 핵심 사실
- 담당: 박철호 교수, 이메일 chpark@kangwon.ac.kr
- [[choi-damseon]]과 개인적 친분이 있는 지인이다
- 2022년 4월 시제품 개발 협업 가능성을 논의했다
- 협업 브랜드명으로 "세인트진"을 제안받았다
