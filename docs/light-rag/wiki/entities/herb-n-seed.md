# 허브앤씨드

허브앤씨드는 [[seongjin]]에 세럼 완제품 견적을 의뢰한 완제품 고객이다. 이주운(Saracen)을
통해 성진과 연결됐다.

## 핵심 사실
- 대표: 최연재(yeonjae4729@gmail.com)
- 완제품: 몰로키아세럼(30mL, 용기·단상자는 사급)
- 2021년 11월 300/1,000/3,000병 단위로 견적을 받았다
- 이주운(Saracen)을 통해 성진과 연결됐다
