# 포천허브농장

포천허브농장은 [[herbsun-farm]]의 레몬버베나스프레이 완제품에 들어가는 원료
레몬버베나수를 공급하는 업체다.

## 핵심 사실
- 공급 품목: 레몬버베나수
- [[herbsun-farm]]의 레몬버베나스프레이 베이스 원료로 쓰인다
