# 코스노바

코스노바(COSNOVA)는 [[seongjin]]에 샴푸 리뉴얼 제조를 의뢰한 완제품 고객이다. 자체
브랜드 '닥터요모' 샴푸를 카페인 0.3% 함유, EWG 1~2등급 기준 처방으로 개정했다.

## 핵심 사실
- 담당자: 황명(altomas@naver.com)
- 완제품: '닥터요모' 샴푸 리뉴얼 — 카페인 0.3%, EWG 1~2등급 처방
- 2022년 3월부터 6월까지 견적서를 여러 차례 개정했다
