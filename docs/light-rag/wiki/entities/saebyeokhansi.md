# 새벽한시

새벽한시(감성디자인)는 주식회사 [[seongjin]]의 패키지 디자인 협력업체다. 담당 장용식 팀장이
산양산삼미스트(=와일드진생안개미스트) 용기·단상자 디자인을 2020년 12월부터 여러 차례
진행했다.

## 핵심 사실
- 담당자: 장용식 팀장, 연락처 010-2300-1803 / am01-@naver.com
- 홈페이지: www.am-01.com
- 2020년 12월부터 산양산삼미스트(=와일드진생안개미스트) 용기·단상자 디자인을 여러 차례
  진행했다
- 전성분 표기 오류 수정, 바코드 삽입, 소비자상담실 전화번호 추가 등 세부 작업까지
  담당했다
- 인쇄업체 [[jeil-print]]와 [[daewon-graphic]]을 [[seongjin]]에 소개했다
- [[seongjin]]과의 관계: 제조·인쇄·디자인 협력업체
