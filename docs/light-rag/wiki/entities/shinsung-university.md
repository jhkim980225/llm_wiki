# 신성대학교

신성대학교는 [[seongjin]] 산하 향기 교육 브랜드 "세인트진"이 발급하는 향기디자이너
2급 지도사 자격증을 재학생에게 발급받아온 교육기관이다. 담당자는 강주희 교수다.

## 핵심 사실
- 담당자: 강주희 교수 (kjh0828@shinsung.ac.kr)
- 세인트진이 발급하는 향기디자이너 2급 지도사 자격증을 2021~2022년 여러 반
  (2학년 1반·2반 등)에 발급했다
