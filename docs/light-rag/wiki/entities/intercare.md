# 인터케어

인터케어는 [[seongjin]]에 원료를 공급하기 위해 접촉한 업체다. 락토바실러스
컴플렉스 원료 공급을 문의했으며, 2021년 5월 신규 거래를 시도했다.

## 핵심 사실
- 연락처: hub@intercare.co.kr
- 취급 원료: 락토바실러스 컴플렉스 계열
- 2021년 5월 [[seongjin]]과 신규 거래를 시도했다 (성사 여부는 확인되지 않는다)
