# 부경대학교 링크플러스사업단

부경대학교 링크플러스사업단은 [[seongjin]]의 기술이전 사업 파트너다. 담당자는
정근혁이며, 모자반 크로마놀b 함유 시제품 개발 사업비 집행을 진행했다. 실제
납품처는 [[psa-company]]다.

## 핵심 사실
- 담당자: 정근혁 (gh2@pknu.ac.kr)
- 2022년 1~2월 모자반 크로마놀b 함유 에센스세럼, 모자반 크로마놀b 함유 바디로션
  시제품 개발 사업비(총 600만원) 집행을 진행했다
- 실제 납품처는 [[psa-company]]다
