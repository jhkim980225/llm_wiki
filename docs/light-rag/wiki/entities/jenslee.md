# 젠슨리

젠슨리((주)젠슨리, 약칭 JSL, jslcos.com)는 [[seongjin]]에 화장품 원료를 공급하는
업체다. 2020년 12월부터 2021년 말까지 반복적으로 거래가 이어졌다.

## 핵심 사실
- 담당자: 배진경(샘플 담당), 김은성(기술 문의), 진혜정(발주 문의, jslcorp@hotmail.com)
- 취급 원료: Beaulight SHAA, Polyaldo 10-1-CC KFG, SAL Butter(사라수씨버터,
  20kg 패킹), 복숭아세라마이드, 제비집추출물
- 복숭아세라마이드는 고가라 무료 샘플을 제공하지 않는다
- 2020년 12월부터 2021년 말까지 반복 거래가 이어졌다
