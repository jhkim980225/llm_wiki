# 세림향료

세림향료(세림에프앤에프, SERIM FLAVOR, serimfnf.com)는 [[seongjin]]에 향료를 공급하는
업체다.

## 핵심 사실
- 담당 창구: sales1@serimfnf.com, qc@serimfnf.com
- 취급 향료: Blooming Bouquet(SR-3766), 두피·피부 제품용 Allergen Free 향료
- 유럽 수출 서류인 IFRA Certificate를 발급받은 이력이 있다
