# 한국품질기술연구원

한국품질기술연구원은 (주)ICR인증원과 함께 [[seongjin]]의 ISO 9001/14001 인증 대행·심사를 수행하는 인증기관이다.

## 핵심 사실
- 담당: 김영남 위원 (010-2620-5555, iso6266@daum.net)
- 2020년 11월 30일 [[seongjin]]에 인증비용 1,540,000원을 청구했다
- 2020년 12월 1일 문서심사, 2020년 12월 9일 현장심사를 진행했다
