# 에스아쉬코스메틱

에스아쉬코스메틱(S-ASHE COSMETICS)은 광주광역시에 있는 화장품 완제품 처방 개발 고객이다.
[[seongjin]]과 비밀유지계약서를 체결하고, 닥터라이제 플라센타크림·닥터라이제 모이스춰크림의
처방을 방부제 대체 등으로 수정하는 작업을 2020년 12월부터 2021년까지 진행했다.

- 주소: 광주광역시
- 완제품: 닥터라이제 플라센타크림, 닥터라이제 모이스춰크림
- 2020년 12월부터 2021년까지 방부제 대체 등 처방 수정 작업을 진행했다
- [[seongjin]]과 비밀유지계약서(NDA)를 체결했다
