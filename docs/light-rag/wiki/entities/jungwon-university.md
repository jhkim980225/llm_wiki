# 중원대학교

중원대학교는 뷰티학과의 문지선 교수를 통해 [[seongjin]]과 접촉한 교육기관이다. 2022년
4월 문지선 교수가 "차세대 바이오헬스산업 혁신인재양성 사업" 산학협력 컨소시엄 참여를
[[choi-damseon]]에게 제안했다.
