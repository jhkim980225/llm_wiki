# 주식회사 더아름

주식회사 더아름은 경기 고양시 덕양구에 있는 화장품 브랜드사로, [[seongjin]]에 크림·
앰플 완제품 개발을 의뢰한 완제품 고객이다. 아로마 전문몰 "맑을담"(dammall.co.kr),
니치향수 "르퍼퓸", "존스멜" 브랜드를 운영한다.

## 핵심 사실
- 대표: 안정준(jjclub1@nate.com, 010-9351-9651)
- 주소: 경기 고양시 덕양구
- 운영 브랜드: 맑을담(아로마 전문몰, dammall.co.kr), 르퍼퓸(니치향수), 존스멜
- 완제품: 베이스크림(수분크림) 4종, 부스터앰플 각 4~16종 개발
- 2022년 3월부터 지속적으로 처방·pH·향 협의를 진행했다
