# 굿프라이스 푸드머신

굿프라이스 푸드머신(코리아팩 굿프라이스)은 [[seongjin]]에 생산설비를 판매한
업체다. 2021년 1~2월 충진기와 튜브실링기를 공급했고, 이후 A/S 요청도 받았다.

## 핵심 사실
- 연락처: foodmachine1004@naver.com
- 판매 품목: 충진기, 튜브실링기
- 2021년 1월~2월 [[seongjin]]이 충진기·튜브실링기를 구매했다
- 이후 누유 문제 등으로 A/S를 요청받았다
