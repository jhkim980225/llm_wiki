## 문제

"원태호"라는 이름이 서로 다른 3개 원료 거래처의 대표/담당자로 등장한다:

- [[laon-trading]] (라온무역) — 원태호 **차장**
- [[gd-chem]] (지디켐) — 원태호 **대표(CEO)**
- [[taeseong-chem]] (태성켐) — 원태호 **대표**

배치 추출 중 여러 에이전트가 독립적으로 이 중복을 발견하고 "동일인인지 동명이인인지
확인 필요"라고 표시했다.

## 근거

직접 원본 이메일을 재파싱해 서명 블록을 대조했다.

**라온무역** (`20201230_1103_RE_ RE_ [성진] 원료 샘플 요청의 건.eml`, 2020-12-30):
```
라온무역 Laon Trading Co,.Ltd
원태호 차장
t 010-5250-5261|f 070-7614-3823|e laontrading@daum.net
a 경기도 화성시 동탄첨단산업1로 14 KTX 밸리 712호
```

**지디켐** (`20220223_3003_[성진] 원료 구매발주서 송부의 건.eml`, 2022-02-23):
```
지디켐 (GD Chem)
원 태 호 / Taeho Won
대     표 / C E O
Mobile. 010-5250-5261
E-Mail. gdchem@gdccare.com
T . 031-8042-4445
A . 경기도 시흥시 서울대학로 59-20, 10층 1026호
```

**휴대폰 번호가 010-5250-5261로 완전히 일치한다.** 회사명·직함·주소는 다르지만
개인 번호가 같다 — 우연으로 보기 어렵다.

**태성켐**은 대조 자료가 없다. `20220330_3217`, `20220412_3317` 둘 다 성진→태성켐
발주/요청 메일이라 성진 측 서명만 있고, 태성켐 원태호 본인의 회신·서명 블록을 담은
파일을 찾지 못했다. 이름과 업종(원료 벤더)만 겹친다.

## 판단

- **라온무역 = 지디켐: 동일인으로 확정.** 휴대폰 번호 일치가 결정적 증거. 2020년
  12월 라온무역 차장이었다가 2021년 8월(첫 지디켐 이메일 확인 시점, `2211`) 이전에
  지디켐을 창업해 대표가 된 것으로 보인다 — 같은 원료 유통업 내 이직/창업.
- **태성켐: 미확정.** 동일인일 가능성이 낮지 않지만(같은 업종, 같은 이름, 비슷한
  시기), 확증할 서명 자료가 없다. 추정으로 문서에 반영하지 않았다.

## 후속 조치

- [[laon-trading]], [[gd-chem]] 문서에 "동일인으로 추정(휴대폰 번호 일치 확인)"으로
  갱신 필요 — 현재는 "동명이인인지 확인 필요"라는 보류 문구만 있다
- [[taeseong-chem]]은 현재 문구(불분명) 유지
- 태성켐 원태호의 회신 메일을 원본에서 추가로 찾으면 이 이슈를 닫는다
