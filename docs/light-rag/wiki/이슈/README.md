# 데이터 이슈 폴더

`wiki/` 문서를 원본에서 만들면서 발견한 **데이터 품질 문제**를 여기 쌓는다. 위키 개체
문서(`entities/`, `sources/`)와는 성격이 다르다 — 이건 LightRAG에 색인할 콘텐츠가
아니라, 문서를 만드는 우리(큐레이터)를 위한 내부 QA 기록이다.

## 언제 이슈를 만드나

- 같은 이름이 서로 다른 인물/조직을 가리키는 것 같을 때 (동명이인)
- 원본마다 사실이 다르게 나올 때 (담당자 교체, 소속 변경, 상반된 정보)
- 개체 정답지(`entities:`)를 채우기엔 근거가 불충분할 때
- 그 외 "본문만 보고는 확신 못 하는" 모든 판단 보류 사안

## 파일 형식

`{slug}.md` 하나당 이슈 하나:

```yaml
---
id: {slug}
title: {한 줄 이슈명}
type: 동명이인 | 사실불일치 | 정보부족 | 기타
status: open | resolved
found_date: YYYY-MM-DD
related: [id1, id2, ...]   # 영향받는 wiki 문서 id (entities/sources 불문)
---

## 문제
{무엇이 이상한가}

## 근거
{실제 원본에서 확인한 사실 — 파일 경로·인용 포함}

## 판단
{현재 결론: 확정/미확정/추정. 왜 그렇게 판단했는지}

## 후속 조치
{resolved라면 무엇을 어떻게 고쳤는지. open이라면 뭘 더 확인해야 하는지}
```
