# 시드 스크립트 (⑥ 색인)

[파이프라인.md](파이프라인.md) ⑥단계 상세. `docs/light-rag/wiki/{entities,sources}/*.md`
중 `status: reviewed`인 문서만 골라 LightRAG에 색인하는 스크립트.

기존 `scripts/lightrag-seed.py`는 **Postgres `Page` 테이블**이 소스라 재사용 못 한다 —
이번 소스는 로컬 마크다운 파일(`wiki/`)이다. 별도 스크립트
`scripts/lightrag-wiki-seed.py`로 만든다.

## 무엇을 하나

1. `docs/light-rag/wiki/{entities,sources,concepts}/*.md`를 로컬에서 직접 읽는다
   (Postgres 버전과 달리 SSH/DB 조회 불필요 — 파일이 이미 여기 있다)
2. 프론트메터를 파싱해 `status: reviewed`가 아니면 건너뛴다
3. 프론트메터(`^---`~`---`)를 제거한다. **본문은 이미 `# {title}`로 시작하므로
   따로 제목을 앞에 붙이지 않는다** (기존 Postgres 버전은 `content`에 제목이 없어서
   `f"# {title}\n\n{content}"`로 붙였지만, `wiki/` 문서는 [TEMPLATE.md](TEMPLATE.md)
   본문 구조상 이미 `# {title}`이 첫 줄이라 그대로 쓴다)
4. `POST /documents/text`로 전송, `file_source`는 문서 `id`

## 접속·제약 (`운영.md` 실측 기준)

- **개발 PC(VPN)에서 NodePort 직접 접근이 막힐 수 있다** (카카오 Fuseki 전례) — 기존
  스크립트와 동일하게 **마스터(200) SSH 경유**로 curl한다. paramiko, 페이로드는
  base64로 넘겨 쉘 이스케이프 회피
- **완전 순차 처리(필수)** — 2026-08-29 82건을 한꺼번에 큐에 넣었다가 6번째 문서에서
  임베딩(Ollama, 직렬 처리) 60초 타임아웃 → **파이프라인 전체가 halt되며 나머지
  76건이 자동 취소**된 사고가 있었다(`운영.md` 참조). 그래서 이 스크립트는 여러 건을
  받아도 **한 번에 하나씩만** `/documents/text`에 태우고, 그 문서가 `processed`/
  `failed`로 끝날 때까지(`GET /documents` 폴링, 기본 6초 간격·150초 상한) 기다렸다가
  다음 문서를 제출한다. 이 방식이라면 `--limit`을 몇으로 잡든 안전하다
- **비용**: 30건 색인에 입력 25만~35만 + 출력 5만~8만 토큰 ≈ $0.11~0.17 (LUNA). 87건이면
  단순 비례로 $0.3~0.5대, 다만 `wiki/` 문서가 운영 위키보다 짧아 실제로는 더 쌀 수 있다
- **같은 id 재색인 거부** — "already contains" 응답. 스크립트가 자동으로 건너뛴다.
  갱신하려면 WebUI에서 먼저 지워야 한다 (덮어쓰기 없음)
- **emptyDir** — 파드 재시작하면 색인 전부 소실. 재시드 필요

## CLI

```powershell
$env:FEDA_PW = '...'                                   # docs/서버정보.md
py scripts/lightrag-wiki-seed.py                        # 기본 5건 (reviewed 중 앞에서부터)
py scripts/lightrag-wiki-seed.py --limit 20              # 건수 조절
py scripts/lightrag-wiki-seed.py --id seongjin --id jeong-ara   # 특정 문서만 (--limit 무시)
py scripts/lightrag-wiki-seed.py --dry-run                # 전송 없이 대상·본문 미리보기
py scripts/lightrag-wiki-seed.py --limit 100 --timeout 200 # 대량 색인, 문서당 대기 상한 늘리기
py scripts/lightrag-wiki-seed.py --query "정원가게는 어떤 회사야?"  # 색인 후 질의 테스트
```
