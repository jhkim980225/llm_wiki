# LightRAG 테스트 가이드

LightRAG를 써 보고 기존 RAG와 비교하는 방법. 운영·설정은 `운영.md`, 판단 근거는 `검토.md`.

## 1. 사이트에서 테스트 (손으로)

1. `https://cloud.fedaground.com/graphwiki` → **bench / 1234** 로그인
   (LightRAG 탭은 bench 계정에만 보인다 — 다른 계정엔 없음)
2. 사이드바 `LightRAG` 탭 → 질문 입력, 모드 선택 → 질문 (Ctrl+Enter)
3. 같은 질문을 `채팅` 탭에도 던져 답변·출처·속도를 비교한다
   - 기존 채팅: 출처가 `[[위키링크]]`라 클릭해 원문으로 이동 가능
   - LightRAG: 문서명 각주만 (이동 불가)

## 2. 검색 모드 5종

| 모드 | 검색 방식 | 이런 질문에 |
|---|---|---|
| naive | 원문 청크 벡터만 (그래프 무시) | 세부 숫자 — "단가가 정확히 얼마?" |
| local | 개체 중심 (그래프) | 특정 대상 — "정아라가 맡은 업무는?" |
| global | 관계·주제 중심 (그래프) | 넓은 질문 — "협상은 보통 어떻게 진행돼?" |
| **hybrid** | local + global (기본값) | 대부분의 질문 |
| mix | hybrid + naive 전부 | 그래프에 안 뽑힌 세부까지 필요한 복합 질문 |

## 3. 추천 질문 (색인 30건 기준)

**naive** — 정재윤테라피 버블폼토너 단가 협의에서 오간 금액은? · 코바상사에 납품한 세럼은 몇 개?
**local** — 정아라 연구원이 담당하는 업무는? · 코바상사와의 거래 이력 정리해줘 · 최담선 연구소장 담당 영역은?
**global** — 견적서 작성과 단가 결정 흐름은? · 원료 구매부터 발주까지 프로세스 설명해줘
**hybrid** — 김종태 대표이사의 최근 주요 의사결정과 배경은? · 두피케어 라인과 관련 거래처 현황 같이 정리해줘
**mix** — 8월 주간 업무내역 종합하면 생산·출고 반복 이슈는? · 세금계산서 발행·입금 최근 처리 건과 담당자는?

같은 질문을 naive ↔ hybrid로 바꿔 던지면 그래프가 실제로 뭘 보태는지 바로 보인다.

## 4. 자동 벤치마크 (기록용)

```powershell
py scripts/lightrag-bench.py          # 내장 질문 15개 전체 — 30~40분
py scripts/lightrag-bench.py --n 3    # 앞 3개만 (스모크)
py scripts/lightrag-bench.py --mode mix
```

15개 질문을 LightRAG와 기존 채팅에 자동으로 던져 `docs/light-rag/벤치마크-<날짜>.md`에
문항별 A/B 답변 + 소요시간을 저장한다. 요약표의 "정확한 쪽" 열은 사람이 채운다.
질문 교체는 스크립트 상단 `QUESTIONS` 목록 수정.

## 5. 그래프·색인 상태 구경 (WebUI)

`http://192.168.0.103:31930/webui` — API Key `lightrag-poc-sj-2026` (최초 1회 입력)

  (튜닝 항목 — `운영.md` 주의사항)

## 6. 문서 추가로 넣기

```powershell
$env:FEDA_PW = '...'                       # docs/서버정보.md
py scripts/lightrag-seed.py --limit 50     # 사람·AI 문서 최근순
py scripts/lightrag-seed.py --slug ejkim/정아라   # 특정 문서 (적재본 포함 아무거나)
```

이메일·카톡 원본을 테스트하려면 적재본 slug(`ejkim/…`, `kakao/…`)를 `--slug`로 지정.
색인은 문서당 2~4분 순차 처리 — 대량이면 `운영.md`의 속도 상한 항목 먼저 볼 것.

## 7. 평가 포인트

- 원문 세부(단가·수량·날짜)를 정확히 집는가 — naive vs 기존 의미검색
- 여러 문서에 걸친 관계·요약 질문에서 더 잘 엮는가 — hybrid·mix의 존재 이유
- 출처 추적이 충분한가 — 기존은 위키링크 이동, LightRAG는 문서명뿐
- 응답 시간 — 실측 LightRAG 20~30초, 기존 채팅 30~90초(소스 RAG API 대기 포함)
