## 시드 (색인)

```powershell
$env:FEDA_PW = '...'                        # docs/서버정보.md
py scripts/lightrag-seed.py --limit 30      # 사람·AI 문서(500자↑) 최근순
py scripts/lightrag-seed.py --slug <slug>   # 특정 문서
py scripts/lightrag-seed.py --query "질문"  # 색인 후 질의 테스트
```

운영 위키 DB(Postgres) 본문을 그대로 복사해 넣는다. 마스터 SSH 경유.

## 주의 (실측)

- **emptyDir** — 파드 재시작하면 색인 전부 소실, 재시드 필요. 본격 사용 시 PVC(cephfs-sc) 전환
- **속도** — 사용량 상한(MAX_ASYNC_LLM=2, MAX_PARALLEL_INSERT=1) 때문에 문서당 2~4분 순차.
  30건 ≈ 1시간+. 병렬 올려도 총비용 동일 — 대량 색인 전에 상한부터 올릴 것(재시작 = 색인 소실 주의)
- **같은 slug 재색인 거부** — "already contains" 응답. 갱신하려면 WebUI에서 삭제 후 재삽입
- **개체가 영어로 추출되는 경향** ("성진"→"Seongjin"). 한국어 질의 매칭에 영향 가능 —
  문제되면 추출 프롬프트에 한국어 유지 지시 검토
- 색인 30건 비용 추정: 입력 25만~35만 + 출력 5만~8만 토큰 ≈ $0.11~0.17 (LUNA 로그·API로는
  토큰 실측 불가 — 정확한 값은 OpenAI 대시보드)

## 벤치마크

`py scripts/lightrag-bench.py [--n 3] [--mode mix]` — bench 계정으로 로그인해 같은 질문 15개를
LightRAG(`/api/lightrag`)와 기존 채팅(`/api/chat` ephemeral)에 던지고
`docs/light-rag/벤치마크-<날짜>.md`에 나란히 기록. 정확/우세 판정 열은 사람이 채운다.
bench 계정: bench / (BENCH_PW env, 기본 1234). 채팅이 문항당 1~3분 — 전체 수십 분.

## 질의 모드 5종

naive(원문 벡터만) · local(개체 중심) · global(주제·관계) · hybrid(local+global, 기본) ·
mix(hybrid+naive 전부). 상세와 모드별 추천 질문은 `검토.md` 5절과 원 리포 README `Query Param` 절.

## 제거 절차

`/api/lightrag`·configmap LIGHTRAG_* 두 줄 제거.
