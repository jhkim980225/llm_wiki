# 사이트 내 사용자 가이드 (2026-08-13)

## 결정

`docs/manual/사용자-매뉴얼.md`를 단일 소스로 사이트 안 `/guide` 화면에 렌더한다.
별도 가이드 문서를 새로 쓰지 않는다 — 매뉴얼과 이중 관리를 피한다.

## 구조

- `src/app/guide/page.tsx` — 서버 컴포넌트. 빌드 시점에 매뉴얼 md를 `fs.readFile`로 읽어
  기존 `Markdown` 컴포넌트로 렌더. `force-static`이므로 standalone 이미지에 `docs/`가
  없어도 동작한다(읽기는 빌드 때 일어난다).
- 캡처 PNG 11장은 `public/manual/img/`에 복사(커밋). md의 `img/…` 상대경로는 렌더 전에
  `/graphwiki/manual/img/…`로 치환한다 — 맨 `<img>`에는 Next가 basePath를 안 붙이므로.
- 진입점 2곳: 글로벌 레일 하단 `도움말`(설정 위) + 홈 들머리 항목 1개.

## 유지보수

화면이 바뀌면 기존 관행(매뉴얼 캡처·PDF 재생성)에 **public 이미지 복사**가 추가된다.
CLAUDE.md 문서 지도에 반영.

## 하지 않는 것

- 화면별 팝오버 도움말, 인터랙티브 투어 — 필요해지면 그때.
- 매뉴얼 md 가공(목차 생성 등) — 원문 그대로 렌더.
